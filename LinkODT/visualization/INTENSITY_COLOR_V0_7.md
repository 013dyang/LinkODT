
Visualization v0.7 intensity color behavior
===========================================

Change:
- XYZ+Intensity point clouds now default to a green intensity gradient.
- Low intensity = darker shade of the selected base color.
- High intensity = brighter shade of the selected base color.
- Choosing Object Color while Color by intensity is enabled no longer disables intensity coloring.
  Instead, the selected color becomes the base hue for the intensity gradient.
- RGB point clouds / instance colors are unchanged.
