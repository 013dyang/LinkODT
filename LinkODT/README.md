# LinkODT application

See the repository [README](../README.md) for setup and collaboration.

Run `python LinkODT.py` from this directory with Python 3.11 and the project
dependencies installed. `RUN_LinkODT.bat` can use an existing environment.

`LinkODT.py` is the launcher; `LinkNex.py` retains the main implementation.
Shared appearance settings are in `ui_theme.py`. Studio UI and display-range
controls are in `visualization/studio_ui.py` and `visualization/display_controls.py`.

For the complete operating instructions, build the
[bilingual user guide](../README.md#user-guide).
