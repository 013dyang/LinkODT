进阶使用与批量分析
==================

从已有结果继续
--------------

无需每次从原始 TIFF 重跑。已有二值掩膜时进入 Instance segmentation；已有实例点云和骨架时进入 Network analysis；仅需制作三维图片和动画时进入 Visualization。

1. 将同一样本的原图、掩膜及 ``processed_output`` 保持在相邻目录。
2. 在模块 3 或 4 直接打开文件或文件夹。
3. 检查自动识别的样本名和状态，再选择运行或浏览。
4. 更改上游掩膜后，依次更新实例和网络，避免将新图像与旧表格组合。

批量操作
--------

静态模块中的 All 处理当前加载列表。动态模块的 Processing scope 切换 Current dataset / All loaded datasets。首次处理新批次时，先选择一个代表性样本，检查尺寸、标定、输出目录和运行日志，再扩展到全部数据。

不同实验组建议使用不同目录，以一致的样本编号串联原图、掩膜和表格。文件名中保留生物重复、时间点与通道信息；不要把自动生成的实例编号当成生物重复编号。

统一参数与复现
--------------

每次批次记录：源码版本、环境、模型文件、分割阈值、图像标定、网络距离、时间间隔、追踪半径和输入清单。修改网络参数时勾选 Overwrite existing network results。动态分析重跑会清理部分旧的下游输出；保存需要比较的上一版结果后再执行。

学习模型与数据增强
------------------

``semantic_models.py`` 管理多种分割模型。GUI 的 Backbone、模型架构与权重必须匹配。完整分割权重包含任务解码器；仅有 DINOv2 编码器权重时，仍需进行下游训练。

项目的 ``ssl/`` 提供独立的自监督训练脚本。在文件内的 USER CONFIG 中设置输入目录、输出目录和 backbone，检查本机路径后通过 Python 运行。

``paired_tiff_segmentation_augmentation_full.py``、``microscopy_segmentation_augmentation_full_v2.py`` 和 ``evaluate_masks_with_panels_v2.py`` 为独立增强/评估工具。先查看脚本配置和输入约定，使用数据副本验证。增强后的同源图像应跟随原始样本划入同一个训练/测试分组，防止同一对象的变体分布在两边。

模型选择建议
------------

用相同的数据划分比较候选架构，检查 Dice、边界、细小对象、速度和显存。除训练曲线外，保存失败案例与独立测试结果。训练界面每轮查看的测试预览会影响人工选择模型；正式性能报告应保留额外独立样本。

批量处理前
------------------------------------------------------------

逐阶段检查一个代表性样本：实际读取维度 → 已保存掩膜 → 实例标签与形态 → 网络输出。用于比较时保持模型、预测阈值、标定和网络距离设置一致，并随输入样本清单保存参数。

修订掩膜后，重新执行对应实例分析，再重新执行网络分析；此前保存的表格仍描述旧掩膜。修改网络距离或尺度后，重新计算网络输出。显示亮度、颜色和相机调整仅改变呈现效果，不更新定量表格。
