系统要求与依赖
==============

软件要求
--------

Windows 独立运行版无需安装 Python。源码版请使用 Python 3.11，并安装项目依赖；Studio 的运行模块需要此版本。

当前模块 4 后端兼容 NumPy 1.x 与 2.x 的积分接口；配置时核对图像处理及二进制依赖兼容性，见 :doc:`faq`。

硬件选择
--------

当前项目没有附带经基准测试确认的最低 RAM、显存或 CPU 配置表。选择设备时按工作负载评估：

* 二维图像浏览和少量样本处理：先验证 TIFF 加载与 GUI 响应。
* 三维大体积图像：体素集合、表面网格、骨架和邻接结构可能同时驻留内存。
* 模型训练/预测：显存需求随 backbone、tile size、batch size 和精度设置变化。
* 动画导出：更高分辨率增加渲染时间、显存和磁盘使用量。

例如一个 100×1024×1024 的 uint16 堆栈，仅原始数组约 200 MiB；处理中间浮点数组、标签和几何还需额外内存。该示例只说明数据规模，不构成整机最低配置。

遇到资源不足
------------

先减少批量和同时载入的样本。训练时降低 **Batch**，或选择合适的较小模型。切块尺寸由源码设置，训练界面没有对应调整控件。三维分析先使用代表性小体积评估峰值内存，再规划整批计算。视频先用 1× 分辨率预览，通过后再导出高分辨率版本。

模型与网络访问
--------------

预训练模型文件未全部包含在当前项目中。下载脚本需访问相应模型源；离线电脑应预先准备权重并按配置放置。GGUF 仅用于可选 AI Director。常规手动三维展示无需本地语言模型。
