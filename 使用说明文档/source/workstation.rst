工作站与远程运行
================

运行方式
--------

LinkODT 是桌面 GUI 项目。当前版本没有经过核验的一键 Slurm / HPC 批量入口。需要远程操作 GUI 时，在工作站准备可用的图形桌面和依赖环境，通过远程桌面进入后启动 ``LinkODT.py``。

1. 将项目、数据和模型复制到工作站的独立目录。
2. 在工作站配置环境并运行环境检查；本机环境不能直接作为远端 Python 环境使用。
3. 确认远端 GPU、驱动及 CUDA 可用，再开展训练或预测。
4. 用小样本验证 TIFF 读取、VTK 三维显示和输出权限。
5. 完成后将结果表、日志、参数和展示文件带回，保留样本目录关系。

计算与查看分离
--------------

可以在计算机 A 生成实例结果，在计算机 B 使用模块 3/4 直接载入。复制时同时保留骨架、点云、标签映射和 CSV。网络 PKL 是中间对象保存格式，跨环境载入受依赖版本影响；交换定量结果时同时保存 CSV。

无显示服务器的计算节点不能直接假定支持 Qt/VTK 窗口。若需将后端接入队列，应由开发者先封装输入参数、日志和退出状态，并用同一小样本与 GUI 结果对照。本手册未将该扩展作为已提供的操作命令。

检查传输文件
------------------------

传输前后比较相对路径、文件数量和大小；传输后打开一组图像和对应掩膜，检查能否正常读取、尺寸是否一致。长时间任务将输出写到有足够空间的工作目录，保留处理日志，以便判断是计算完成、被中止还是仅生成了部分文件。
