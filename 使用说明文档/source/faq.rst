常见问题与故障排查
==================

双击 RUN_LinkODT.bat 无法启动
----------------------------------------------

使用 LinkODT 项目目录中的 ``RUN_LinkODT.bat``。脚本优先使用指定的 ``LINKODT_PYTHON``，随后查找本地 ``.linkodt_runtime``、已激活的 Conda 环境或 PATH 中的 Python。确认所选环境包含项目依赖，也可激活环境后运行 ``python LinkODT.py``。旧 ``RUN_LinkNex.bat`` 保留为启动别名。

运行 main.py 没有出现 LinkODT
----------------------------------------------

根目录 ``main.py`` 是示例文件。主入口为 ``LinkODT.py``；可视化独立入口为 ``visualization/main.py``。

提示缺少 pyvistaqt、Qt 或 VTK
----------------------------------------------

在实际启动所用环境安装依赖，然后重跑 ``tools/check_environment.py``。若 QtCore 出现 DLL 导入失败，检查 Python/Qt 版本与安装完整性。

网络计算提示 numpy 没有 trapezoid
--------------------------------------------------

LinkODT 3.2 优先使用 ``numpy.trapezoid``，在 NumPy 1.x 中使用等价的 ``numpy.trapz``。若仍出现此错误，检查启动的是否为当前项目副本；重跑后核对最终日志与输出表。

找不到 DINOv2 / 分割模型
----------------------------------

检查选择的模型架构、backbone 和权重文件是否匹配。编码器预训练权重不包含完整任务解码器。检查 ``models/``、下载脚本及 ``MISSING_EXTERNAL_FILES.txt``；训练或预测日志会给出加载失败的位置。

模块 3 无法运行单层图像
--------------------------

完整实例管线要求至少两层 Z。单层二维掩膜可以在二维分割界面查看；需要三维实例量化时使用实际 Z 堆栈，不能通过复制同一切片制造真实厚度。

导入文件后没有自动发现结果
--------------------------

检查样本基名是否匹配，打开结果的直接父目录或 ``processed_output``。模块 3/4 的直接载入只搜索约定位置，不会遍历任意深层文件夹。仅有 OBJ 不具备重新建立完整网络的输入条件。

修改网络参数后结果没变化
------------------------

检查是否复用了已有结果。勾选 Overwrite existing network results 后重跑，并核对输出时间及参数。仅改变界面数值不会自动更新磁盘上的网络。

动态掩膜生成后画布变黑
----------------------

LinkODT 3.2 通过 GUI 线程中的 QObject 槽接收后台完成与错误回调。八帧示例掩膜生成、自动进入掩膜视图及后续切帧已通过，未出现 Qt 线程警告。若查看区意外为空，检查所选数据集／帧、掩膜前景和日志；反馈时附输入维度及软件版本。

Mask review 中找不到笔刷
------------------------------------

当前 GUI 未连接添加/擦除按钮；旧 README 中相关描述不能作为当前操作入口。掩膜查看与生成可用，人工修订需采用独立 TIFF 编辑流程，并核对逐帧掩膜及查看缓存。详情见 :doc:`dynamics`。

三维数值看起来不像 µm
------------------------

模块 3 的形态学调用固定单位体素标定；模块 4 的 XYZ scale 仅影响网络坐标与距离。动态模块使用自己的 XY、Z 和 Δt 参数。分别检查各模块的单位来源。

图像强度表能否直接比较
----------------------

先确认实例分析成功读取了匹配原图，且采集、背景校正和强度处理一致。缺失原图时使用掩膜占位强度；展示亮度和伪彩色也不能作为原始荧光强度。

报告问题时需要提供什么
----------------------

记录模块、具体按钮顺序、输入尺寸/轴顺序、参数、软件版本和完整报错。附一个可共享的小样本及日志，说明预期结果和实际结果。界面截屏应包含选中样本及参数区。
